文档 /Skill

Skill ​

bubblesjs-i18n 为 AI 编程助手提供 BubblesJS i18n 的接入与词条维护指导，适用于 React、Vue 和普通 JavaScript 项目，以及 JSON 与 Excel 翻译词条的维护。

安装 ​

在项目根目录执行：

sh
pnpx skills add bubblesplant/skills --skill bubblesjs-i18n

按命令提示选择正在使用的 AI 编程助手，并完成安装。

使用 ​

安装后，向助手说明要使用 bubblesjs-i18n，并描述你的需求。例如：

请使用 bubblesjs-i18n，为当前 Vue 项目接入国际化，准备中文和英文 JSON 词条，并支持切换语言。

请使用 bubblesjs-i18n，配置命令行工具扫描项目中的翻译 key，并把 JSON 词条导出为 Excel，方便翻译后导入。

具体接入步骤可查看 React、Vue 和 命令行工具使用指南。
