实现思路：核心与框架分层

核心容器管理语言、词条与订阅；React 和 Vue 将状态变化接入组件，让翻译随语言更新。

↗

React：Provider + useI18n

创建 store，用 I18nProvider 包住组件，再调用 useI18n() 获取 tr、locale 和 loadLocale。

↗

Vue：Provider + useI18n

创建 store，通过 I18nProvider 注入；在 setup 中调用 useI18n()，在模板中用 tr() 翻译。

↗

CLI：扫描项目 → JSON

sync 扫描静态 tr() 调用并同步 JSON；check 检查词条差异。同步时保留已有翻译，也可先预览。

↗

语言切换：加载后更新组件

用 loaderMessage 按需加载 JSON，通过 loadLocale 切换语言。加载完成后，订阅状态的组件自动刷新。

↗

JSON ⇄ Excel：设计阶段

计划把 JSON 导出为表格供翻译编辑，再导回语言包。当前 CLI 尚未实现 Excel 导入导出。
