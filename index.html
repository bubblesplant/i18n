# 你好，Bubbles.
TS i18n.ts ●
const store = createI18n({
  locale: 'zh-CN',
  message: { welcome: '你好，{name}！' }
})
const { tr } = store.getState()
tr('welcome', { name: 'Bubbles' })

✧✧

轻量核心，专注翻译

扁平词条、占位符插值与状态订阅。用一个框架无关的容器，连接你的语言与界面。

↗

React，熟悉的 Hooks

通过 Provider 隔离组件子树的语言，用 Hooks 订阅状态，让翻译自然融入组件。

↗

Vue，顺手的响应式

Provider 与 Composables 连接同一套核心，在组件卸载时自动清理订阅。

↗

词条 CLI，维护有序

扫描静态翻译调用，补全 JSON 语言包并保留已有翻译。预览、检查与清理，都有据可循。

↗

异步语言，从容切换

按需加载词条，记住用户的语言偏好。切换期间保留当前内容，最后一次选择优先。

↗

按需组合，自由接入

核心、框架适配与 CLI 分别安装。提供 ESM、CommonJS 和 TypeScript 声明，支持服务端渲染。
